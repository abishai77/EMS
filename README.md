# EMS
🧑‍💼 Employee Management System (EMS)

Employee Management System (EMS) is a Java-based web application developed using JSP, Servlets, JDBC, and MySQL. The application follows the MVC (Model-View-Controller) architecture to ensure proper separation of concerns and maintainable code structure.

🚀 Features

Add new employee records

View all employees

Update employee details

Delete employee records

Search employees by ID or name

Secure database connectivity using JDBC

Structured project using DAO design pattern

🛠️ Technologies Used

Java (JDK 11)

JSP & Servlet

JDBC

MySQL

Apache Tomcat

Maven

🗄️ Database

The application uses a MySQL database (ems_db) with an employee table containing:

id (Primary Key, Auto Increment)

name

email

department

salary

Phone Number

📂 Architecture

The project follows MVC architecture:

Model → Employee class

View → JSP pages

Controller → Servlets

DAO Layer → Handles database operations

Utility Layer → DBConnection class

🎯 Purpose

This project demonstrates practical implementation of:

Java Web Development

Database connectivity using JDBC

CRUD operations

MVC design pattern

Layered architecture
